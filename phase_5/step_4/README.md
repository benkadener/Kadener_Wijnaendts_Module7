# Step 4: Fit both models

With θb fixed to measured mean T1 − Tamb, fit one positive parameter m by unweighted least squares to T2–T5. T1 has zero residual by construction. Both fits use the same measured boundary, five positions, and ambient.

$$\theta_f(x)=\theta_b\frac{\cosh[m(L-x)]}{\cosh(mL)},\qquad \theta_\infty(x)=\theta_b e^{-mx}.$$

The finite solution assumes an insulated tip: dθ/dx at L is zero. Neither fit establishes stationarity or validates this boundary condition.
