# Step 7: Effect of ignoring the finite end

Δm = m_semi − m_finite = **-2.3745 m⁻¹** (-40.9% relative to finite m). The magnitude is 13.10 times the finite-fit conditional SE and 9.69 times the exponential-fit conditional SE. An independence-based SE combination is 0.3049 m⁻¹, but the fits share the same data, so this is only a scale comparison, not a significance test. Geometry sensitivity and unknown ambient uncertainty are separate.
